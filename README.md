# 🎮 Projet Fil Rouge – Ludothèque Interactive

Ce projet a été réalisé dans le cadre de ma formation, au sein d’une entreprise fictive nommée **Ludothèque Interactive**.  
L’objectif : développer un **catalogue de jeux en ligne** permettant aux **utilisateurs authentifiés** de :

- ⭐ Évaluer un jeu  
- 💬 Laisser un commentaire  
- 🔍 Consulter les fiches détaillées des jeux  

Ce projet constitue une première version fonctionnelle, et **une refonte complète est prévue** afin d'améliorer l'architecture, le design, l'expérience utilisateur et la qualité du code.

---

## 🚀 Objectifs pédagogiques

- Développer un **projet complet full-stack**
- Concevoir une **base de données relationnelle**
- Utiliser une architecture **.NET / Razor Pages**
- Travailler avec un **frontend statique HTML/CSS/JS**
- Déployer le projet via **Docker**
- Utiliser un **workflow Git/GitHub professionnel**
- Produire une **documentation claire**

---

## 🛠️ Stack technique

| Domaine | Outil / Technologie | Rôle |
|--------|---------------------|------|
| 🎨 Design / Maquettes | **Figma** | Wireframes, prototypes UI/UX |
| 💻 Frontend | **HTML / CSS / JavaScript (VS Code)** | Intégration responsive, interactions |
| ⚙️ Backend | **.NET / Razor Pages (Visual Studio)** | Logique serveur, gestion des routes |
| 🐘 Base de données | **PostgreSQL (Docker + DBeaver)** | Gestion des données persistantes |
| 🐋 Conteneurisation | **Docker / Docker Compose** | Environnements reproductibles |
| 🌐 Versionnement | **GitHub** | Suivi, collaboration, démo |
| 📓 Gestion de projet | **Notion** | Planning, documentation, suivi |
